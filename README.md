# ইমোন এন্টারপ্রাইজ — Emon Enterprise

SKB স্টেইনলেস স্টিল কাপড় শুকানোর হ্যাঙ্গারের মোবাইল-ফার্স্ট অনলাইন শপ।
সম্পূর্ণ বাংলা কনটেন্ট, বাংলাদেশি টাকা (৳) ও বাংলা অঙ্ক, অর্ডার যায় সরাসরি **হোয়াটসঅ্যাপে** — কোনো ব্যাকএন্ড, ডেটাবেস বা অ্যাডমিন প্যানেল নেই।

## ১. লোকালি চালানো

```bash
npm install
npm run dev        # http://localhost:3000
```

প্রোডাকশন মোডে দেখতে:

```bash
npm run build
npm run start
```

> Node.js **১৮.১৮+** (২২ লাইন রেকমেন্ডেড) লাগবে। কোনো এনভায়রনমেন্ট ভেরিয়েবল বা API key লাগে না।

## ২. Vercel-এ ডিপ্লয় (ফ্রি)

1. এই GitHub রিপোজিটরিটি [vercel.com/import](https://vercel.com/import) থেকে Import করুন — Framework **Next.js** সিলেক্ট হবে, বাকি সব সেটিংস অটোমে ঠিক থাকে।
2. Build Command: `npm run build`, Output Directory: খালি রাখুন। কিছু বদলাতে হবে না।
3. `main` ব্রাঞ্চে push করলেই অটো প্রোডাকশন ডিপ্লয় হবে; অন্য যেকোনো ব্রাঞ্চে প্রিভিউ লিংক পাবেন।

সাইটটি সম্পূর্ণ স্ট্যাটিক হিসেবে বিল্ড হয় (কোনো সার্ভারলেশ ফাংশন নেই), তাই Vercel-এর **Hobby (ফ্রি)** প্ল্যানেই আরামে চলবে — কোনো খরচ নেই।

## ৩. নিজের তথ্য বদলানো

সব কিছু এক-একটি ফাইলে জমা আছে; শুধু সেটি এডিট করলেই পুরো সাইটে স্বয়ংক্রিয়ভাবে বদলে যাবে।

| কী বদলাবেন | ফাইল |
| --- | --- |
| দোকানের নাম, ফোন/হোয়াটসঅ্যাপ নম্বর, ঠিকানা, bKash/Nagad নম্বর, ডেলিভারি চার্জ | `lib/site.ts` |
| পণ্যের নাম, দাম, ছবি, স্টক, স্পেসিফিকেশন, রিভিউ | `lib/products.ts` |
| হোম পেজের ট্রাস্ট ব্যাজ, "কেন আমরা", অর্ডারের ধাপ, কাস্টমার রিভিউ, FAQ, ডেলিভারি টেবিল | `lib/content.ts` |
| রঙ, ফন্ট, শ্যাডো | `tailwind.config.ts` |
| বাটন, কার্ড, ইনপুটের বেস স্টাইল | `app/globals.css` |

**সবচেয়ে জরুরি:** `lib/site.ts` এর `whatsappNumber: "8801712345678"` — এটি বদলে দিলেই সাইটের প্রতিটি অর্ডার বাটন আপনার নম্বরে চলে যাবে। ফরম্যাট: কান্ট্রি কোডসহ, `+`, স্পেস বা ড্যাশ ছাড়া।

সংখ্যা লেখার নিয়ম: কোডে ইংরেজি অঙ্কে লিখুন (যেমন `3500`), সাইট সেটি নিজে থেকেই `৳৩,৫০০` করে দেখাবে।

## ৪. ছবি বদলানো

| ছবি | কোথায় আছে | কোন ফাইলে রেফারেন্স |
| --- | --- | --- |
| পণ্যের ছবি (প্রতিটি পণ্যে ২–৩টি ভিউ) | `public/products/*.jpg` | `lib/products.ts` → প্রতিটি পণ্যের `images: [{ src, alt }]` |
| হোম পেজের হিরো | `public/hero/hero-hangers.jpg` | `app/page.tsx`, `app/layout.tsx` (OG ইমেজ) |
| "আমাদের কথা" পেজের ছবি | `public/hero/lifestyle-balcony.jpg`, `lifestyle-laundry.jpg`, `detail-clips.jpg` | `app/about/page.tsx` |
| লোগো ও অ্যাপ আইকন | `public/brand/`, `public/icons/`, `app/icon.png`, `app/apple-icon.png` | `app/layout.tsx`, `app/manifest.ts` |

- সব ছবি ১২০০×৬৫৫ (১৬:৯) — নতুন ছবি তুললে এই সাইজে রিসাইজ করে একই ফাইলনামে বসিয়ে দিলেই হবে।
- আইকন রিজেনারেট করতে: `node tools/make-icons.mjs`
- প্রতিটি `Image`-এ `alt` টেক্সট অবশ্যই বদলান (SEO ও অ্যাক্সেসিবিলিটির জন্য)।

## ৫. সাইটে যা যা আছে

- **হোম** — হিরো, ট্রাস্ট স্ট্রিপ, ক্যাটাগরি টাইল, কম্বো অফার + মধ্যরাত পর্যন্ত কাউন্টডাউন, বেস্টসেলার, "কেন আমরা", অর্ডারের ৪ ধাপ, কাস্টমার রিভিউ, ডেলিভারি টেবিল, FAQ, শেষ CTA ব্যান্ড
- **সব পণ্য** (`/products`) — সার্চ, সর্ট (নতুন আগে / দাম কম→বেশি / বেশি→কম / সেরা রেটিং / সর্বোচ্চ ছাড়), ফিল্টার চিপ, খালি ফলাফলের স্টেট; সার্চ-ফিল্টার URL-এ সিঙ্ক থাকে তাই লিংক শেয়ার করা যায়
- **পণ্যের ডিটেইল** — গ্যালারি (থাম্বনেইল + ট্যাপ-টু-জুম), দাম/এমআরপি/ছাড়/স্টক, পরিমাণ স্টেপার, কার্টে যোগ করুন ও হোয়াটসঅ্যাপে অর্ডার, বিস্তারিত/স্পেসিফিকেশন/রিভিউ ট্যাব, সাইজ গাইড, রিলেটেড পণ্য, স্ক্রলে আসা ফ্লোটিং "অর্ডার করুন" বার
- **কার্ট** (`/cart`) — লাইন আইটেম, পরিমাণ, রিমুভ, ডেলিভারি এলাকা বদলে চার্জ আপডেট, ফ্রি ডেলিভারি প্রোগ্রেস বার
- **চেকআউট** (`/checkout`) — নাম/মোবাইল/জেলা/থানা/ঠিকানা ভ্যালিডেশনসহ, ক্যাশ অন ডেলিভারি·bKash·Nagad, ফর্মের ড্রাফট অটো সেভ, এক ক্লিকে হোয়াটসঅ্যাপে অর্ডার
- **অর্ডার সাকসেস** (`/order-success`) — অর্ডার আইডি, বিবরণ কপি, "এরপর যা হবে" ধাপ
- **অ্যাকাউন্ট** — রেজিস্টার / লগইন / লগআউট, অর্ডার হিস্ট্রি, "আবার অর্ডার করুন" (সব তথ্য ব্রাউজারেই সংরক্ষিত)
- **অন্যান্য** — মোবাইল বটম নেভিগেশন, ফ্লোটিং হোয়াটসঅ্যাপ বাটন, টোস্ট নোটিফিকেশন, অ্যাক্সেসিবিলিটি (skip link, ARIA, reduced-motion), SEO (metadata, canonical, Open Graph, JSON-LD: Store/ItemList/Product, sitemap, robots, PWA manifest)

## ৬. প্রজেক্ট স্ট্রাকচার

```
app/            পেজ ও লেআউট (Next.js App Router)
components/     সব UI কম্পোনেন্ট
lib/            পণ্য ও কনটেন্ট ডেটা, সাইট সেটিংস, কার্ট/অ্যাকাউন্ট/টোস্ট কনটেক্সট, ফরম্যাট হেল্পার
public/         ছবি ও আইকন
tools/          হেল্পার স্ক্রিপ্ট (বাংলা অঙ্ক কনভার্ট, আইকন জেনারেট)
```

## ৭. নোট

- এটি ফ্রন্টএন্ড ডেমো: পেমেন্ট গেটওয়ে নেই, অর্ডার হোয়াটসঅ্যাপ বার্তা হিসেবে যায়, কার্ট/অ্যাকাউন্ট/অর্ডার `localStorage`-এ থাকে।
- পরে আসল অর্ডার সিস্টেম লাগলে Google Sheet, WhatsApp Business API বা যেকোনো ব্যাকএন্ড যুক্ত করা যাবে — তখনও হোস্টিং ফ্রিতেই চলবে।
- কোনো থার্ড-পার্টি ট্র্যাকিং পিক্সেল নেই; সব অ্যাসেট লোকাল (ফন্ট শুধু Google Fonts CSS link দিয়ে)।
